What We Host

Postgres

The default relational database for most projects. A managed PostgreSQL instance is provisioned and kept running, so a small project or prototype gets a real database without operating one.

Application data Prototypes Side projects

Redis

An in-memory store for the jobs a relational database is wrong for. A managed Redis instance handles caching, session state, queues, and rate counters.

Caching Background job queues Ephemeral state

DRP — run your own container

DRP (Docker Run Platform) runs a container you bring — the same platform the managed services run on, available directly. Package your application as a container image and run it alongside your databases and search, in one place, billed the same way as everything else.

Your own application or API A background worker A service we don't offer managed

Meilisearch

A search engine built for speed and forgiving queries. A managed Meilisearch instance adds fast, typo-tolerant full-text search to a project without running search infrastructure.

Site and docs search Autocomplete Product search

L7 — the router, in the cloud

Our layer-7 router, spun up in the cloud like any other service — routing, access control, rate limiting, and protection at the application layer. Try it yourself, wire it to your services, and see how it works before it ever touches production.

Routing and access rules for your services A place to try L7 hands-on A proxy in front of your own containers

This is L7 to run yourself. For a core that's watched — with the engineers who built it stepping in when it breaks — see L7.

Qdrant

A vector database for similarity and embeddings. A managed Qdrant instance stores and searches vectors for semantic and AI-driven features.

Semantic search Recommendations Retrieval for AI features
